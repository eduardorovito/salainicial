Una ficha para conocer la letra B. Tiene la B y la b grandes para decorar, renglones para repasar la mayúscula y la minúscula, una búsqueda para rodear todas las B entre otras letras y un recuadro para dibujar algo que empiece con B. Es parte del [abecedario para imprimir](/fichas/abecedario-para-imprimir/), con las 27 letras.

## Palabras con B

Ballena, barco y botón. Pregunta al grupo: ¿alguien tiene un nombre que empiece con B? ¿Y algún familiar, una mascota o un personaje?

## Cómo suena la B

La B se dice juntando los labios: b, b, b. Suena igual que la V; más adelante aprenderán cuándo se escribe cada una.

## Una rima para decir juntos

> Un barco grande y otro chiquito,<br />
> la ballena Bruna les hace un saludito.

Díganla en voz alta varias veces, marcando con palmas las palabras que empiezan con B.

## Cómo usar la ficha

1. **La letra grande:** decórenla con papelitos de colores, plastilina, lentejas o crayones.
2. **Repasar:** primero con el dedo en el aire y sobre la hoja, después con lápiz. Muestra que las letras se empiezan desde arriba.
3. **Buscar y rodear:** encuentren todas las B y las b, y cuenten cuántas hay. Hay seis escondidas.
4. **Dibujar:** en el recuadro, un dibujo de algo que empiece con B. Si quieren, escribe el nombre debajo mientras lo dictan.

## Una actividad para completar

Junten botones de distintos tamaños y colores y clasifíquenlos en cajitas.
