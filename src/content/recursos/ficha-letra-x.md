Una ficha para conocer la letra X. Tiene la X y la x grandes para decorar, renglones para repasar la mayúscula y la minúscula, una búsqueda para rodear todas las X entre otras letras y un recuadro para dibujar algo que empiece con X. Es parte del [abecedario para imprimir](/fichas/abecedario-para-imprimir/), con las 27 letras.

## Palabras con X

Xilófono, taxi y examen. Pregunta al grupo: ¿alguien tiene un nombre que empiece con X? ¿Y algún familiar, una mascota o un personaje?

## Cómo suena la X

La X suena como ks (taxi, xilófono). En algunas palabras, como México, suena como la J.

## Una rima para decir juntos

> Toca el xilófono Ximena,<br />
> tin, tin, tin, ¡qué música tan buena!

Díganla en voz alta varias veces, marcando con palmas las palabras que empiezan con X.

## Cómo usar la ficha

1. **La letra grande:** decórenla con papelitos de colores, plastilina, lentejas o crayones.
2. **Repasar:** primero con el dedo en el aire y sobre la hoja, después con lápiz. Muestra que las letras se empiezan desde arriba.
3. **Buscar y rodear:** encuentren todas las X y las x, y cuenten cuántas hay. Hay seis escondidas.
4. **Dibujar:** en el recuadro, un dibujo de algo que empiece con X. Si quieren, escribe el nombre debajo mientras lo dictan.

## Una actividad para completar

Armen un xilófono con botellas o vasos de vidrio con distinta cantidad de agua y escuchen cómo cambia el sonido (con supervisión de un adulto).
