En ronda, una persona hace una secuencia breve de sonidos y el grupo la devuelve como un eco. El desafío es escuchar, esperar el turno y descubrir qué parte se repite.

## Ronda inicial

Comienza con una palmada y una pausa. Acuerden una señal para empezar y otra para esperar. Luego prueba dos acciones distintas, como tocar suavemente la mesa y dar una palmada. Deja tiempo para escuchar antes de que el grupo responda.

## Ajustes para el grupo

- **3 años:** repite una acción con un gesto visible. Permite que alguien participe solo con el movimiento.
- **4 años:** alterna dos acciones. Después de repetirlas, pregunta cuál vino primero.
- **5 años:** una pareja inventa una secuencia con tres acciones o una pausa. Otra pareja la representa con dibujos y la enseña al grupo.

Para evitar ruido excesivo, usa las manos sobre las piernas o tarjetas visuales. Las tarjetas también permiten participar a quienes prefieren seguir una señal visual o necesitan un ambiente más tranquilo.

## Qué observar

Mira si el grupo espera la señal, mantiene la secuencia o anticipa el siguiente sonido. Si la respuesta se pierde, reduce la secuencia y repítela visualmente.
