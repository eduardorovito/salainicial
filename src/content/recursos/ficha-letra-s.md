Una ficha para conocer la letra S. Tiene la S y la s grandes para decorar, renglones para repasar la mayúscula y la minúscula, una búsqueda para rodear todas las S entre otras letras y un recuadro para dibujar algo que empiece con S. Es parte del [abecedario para imprimir](/fichas/abecedario-para-imprimir/), con las 27 letras.

## Palabras con S

Sol, sapo y silla. Pregunta al grupo: ¿alguien tiene un nombre que empiece con S? ¿Y algún familiar, una mascota o un personaje?

## Cómo suena la S

La S suena como una serpiente: ssss.

## Una rima para decir juntos

> Sale el sol y el sapo canta,<br />
> se sienta en la silla y se levanta.

Díganla en voz alta varias veces, marcando con palmas las palabras que empiezan con S.

## Cómo usar la ficha

1. **La letra grande:** decórenla con papelitos de colores, plastilina, lentejas o crayones.
2. **Repasar:** primero con el dedo en el aire y sobre la hoja, después con lápiz. Muestra que las letras se empiezan desde arriba.
3. **Buscar y rodear:** encuentren todas las S y las s, y cuenten cuántas hay. Hay seis escondidas.
4. **Dibujar:** en el recuadro, un dibujo de algo que empiece con S. Si quieren, escribe el nombre debajo mientras lo dictan.

## Una actividad para completar

Hagan serpientes de plastilina y usen una para formar la letra S.
