Una ficha para conocer la letra C. Tiene la C y la c grandes para decorar, renglones para repasar la mayúscula y la minúscula, una búsqueda para rodear todas las C entre otras letras y un recuadro para dibujar algo que empiece con C. Es parte del [abecedario para imprimir](/fichas/abecedario-para-imprimir/), con las 27 letras.

## Palabras con C

Casa, conejo y cuchara. Pregunta al grupo: ¿alguien tiene un nombre que empiece con C? ¿Y algún familiar, una mascota o un personaje?

## Cómo suena la C

La C suena fuerte con a, o, u (casa, cono, cuna) y suave con e, i (cebra, cielo). Es una buena letra para jugar a escuchar.

## Una rima para decir juntos

> En la casa del conejo<br />
> hay una cuchara y un espejo.

Díganla en voz alta varias veces, marcando con palmas las palabras que empiezan con C.

## Cómo usar la ficha

1. **La letra grande:** decórenla con papelitos de colores, plastilina, lentejas o crayones.
2. **Repasar:** primero con el dedo en el aire y sobre la hoja, después con lápiz. Muestra que las letras se empiezan desde arriba.
3. **Buscar y rodear:** encuentren todas las C y las c, y cuenten cuántas hay. Hay seis escondidas.
4. **Dibujar:** en el recuadro, un dibujo de algo que empiece con C. Si quieren, escribe el nombre debajo mientras lo dictan.

## Una actividad para completar

Armen una casa con cajas de cartón y busquen en el aula objetos que empiecen con C.
